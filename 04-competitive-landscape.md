## Where Readio wins

**Segment: Lapsed readers and non-readers who want to build a reading habit but have failed with every existing app.**

No competitor owns this segment. Goodreads, StoryGraph, and Bookly all implicitly assume the user already reads. Readio's distinctive competencies (non-reader onboarding, behaviour-change metrics, Reading Receipt) are all designed for a persona the rest of the market ignores.

Readio wins when:
- The user has tried at least one reading app and stopped using it
- The user identifies as someone who "used to read" or "wants to read more"
- The user measures success by habit consistency, not books-per-year count
- The user is intimidated by Goodreads' social performance layer

## Where Readio should not fight

| Area | Why to run | Who owns it |
| :--- | :--- | :--- |
| Social network / community | Goodreads' 150M-user network and Fable's 100K+ clubs are moats that cannot be overcome without 10+ years and massive capital | Goodreads, Fable |
| Content catalog / ebook distribution | Amazon, Apple, Kobo own content. Competing requires publisher deals, capital, and years of catalog building | Kindle, Apple Books, Kobo |
| Power-user knowledge retention | Readwise owns the $120/yr knowledge worker. Readio should not try to compete on spaced repetition or highlight depth | Readwise |
| AI book recommendations (standalone) | Every major app added AI recommendations in 2024–2026. Table stakes within 12 months, no moat possible | Category-wide |

# Solution Matrix — Readio vs. Competitors

**Axes:** X = Impact to Customer (Low → High) · Y = Depth of Investment (Low → High)

| | Low Impact to Customer | High Impact to Customer |
| :--- | :--- | :--- |
| **High Investment** | **"Why?"** — Full social network build (fighting Goodreads); building a content catalog; standalone AI recommendations | **Strategic Vision** — Readio's full habit platform (Reading Receipt + mood discovery + cross-format + non-reader onboarding); Readwise Reader's knowledge retention system |
| **Low Investment** | **Utilities** — Basic book logging (StoryGraph free tier); simple streak tracking; reading list management | **No Brainer** — Reading Receipt (weekly summary); 10-minute daily goal setting; Goodreads import; mood-based discovery; session timer |

### Read-out

**No Brainer (do these first — highest return for lowest investment):**
- Reading Receipt — low build cost, high emotional impact, no competitor has it
- 10-minute daily goal — behaviour-change science; low complexity; addresses the #1 problem
- Goodreads import — removes the primary switching barrier; low build cost, high conversion impact
- Mood-based discovery — StoryGraph proved the demand; Readio's version ties mood to time commitment

**Strategic Vision (big bets — needs business case before committing):**
- Cross-format parity (articles + books in one habit tracker) — significant build effort; potentially the strongest long-term moat
- AI reading coach — personalised nudges based on reading patterns; high impact if done well, costly if done poorly

**Utilities (maintain, don't over-invest):**
- Basic book logging — necessary for trust; not a differentiator
- Streak tracking — hygiene feature; all apps have it

**"Why?" (avoid):**
- Building a social network from scratch
- Building a content/ebook catalog
- Competing with Readwise on highlight retention
